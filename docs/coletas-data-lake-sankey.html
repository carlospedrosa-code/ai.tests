Coletas do data lake: da origem ao consumidor

Fluxo de cada coleta e transformação mapeada: sistema de origem, tecnologia onde o dado está persistido, conector, camadas do lake (landing, raw, staged, curated), camada analítica e consumidores. A largura de cada faixa é o número de fluxos de coleta.

Limites desta versão O Data Asker e o catálogo de dados não estavam acessíveis no ambiente de geração (o MCP Inter-trino falhou ao iniciar e o Data Asker só aparece no Second Brain como sistema externo). Tudo aqui vem do Second Brain, que responde por busca. Por isso a lista não é exaustiva e os consumidores são poucos. Nós tracejados marcam lacunas que o catálogo deve preencher.
